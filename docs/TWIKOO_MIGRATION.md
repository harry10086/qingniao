# 🔄 从 Twikoo 一键平滑迁移至 Qingniao (青鸟)

Qingniao 后台内置了对 Twikoo 导出的 JSON 数据格式的完全兼容与格式自动转换引擎。

---

## 迁移优势
- **保留完整回复树**：自动根据 `_id` 与 `rid` 递归还原原有的所有多层嵌套回复关系。
- **HTML 自动转 Markdown**：自动将 Twikoo 中的 HTML 排版（粗体、斜体、引用、行内代码、代码块等）精准转换为标准 Markdown。
- **保留历史时间戳与赞数**：历史评论的发表时间和点赞数原样保留。
- **垃圾评论标记自动继承**：被 Twikoo 标记为垃圾/违规的评论自动作为 `rejected` 导入，正常评论直接为 `approved`。

---

## 迁移操作指南

### 第一步：从 Twikoo 导出数据
1. 登录你原有的 Twikoo 管理后台。
2. 点击顶部的 **设置** 或 **数据**。
3. 点击 **导出数据**，下载生成的 `.json` 文件。

### 第二步：导入到 Qingniao 管理后台
1. 打开 Qingniao 管理后台页面（`admin/index.html` 或你部署的后台地址）。
2. 输入管理员账号密码登录。
3. 点击操作栏上的 **📥 导入** 按钮。
4. 打开下载的 Twikoo `.json` 文件，全选内容并复制，粘贴到文本框中。
5. **务必勾选「标记为 Twikoo 格式」** 复选框。
6. 点击 **开始导入**。

导入完成后，系统会提示成功导入的数据条数，刷新后台即可查看并管理所有历史评论！
