# 🔄 Qingniao 多平台评论数据导入迁移指南

Qingniao (青鸟) 管理后台内置了强大的**跨平台评论导入与转换引擎**，支持将 **WordPress、Typecho、Waline、Artalk、Twikoo** 等主流系统导出的历史评论一键无缝平滑迁移至 Qingniao。

---

## 🌟 核心优势

- **🌲 完美还原回复嵌套树**：无论历史评论是否按顺序存放，系统均会自动根据原平台 ID 与父级关联 ID 递归构建准确的父子回复链条。
- **📝 HTML 自动转 Markdown**：自动识别并转换加粗、斜体、删除线、超链接、代码块、行内代码、引用块及图片等常用排版，剔除不安全标签。
- **⏱️ 历史时间与数据保留**：完整继承发表时间戳、置顶状态、获赞数与反对数。
- **🛡️ 垃圾评论状态继承**：原系统处于待审核或标记为垃圾的评论将自动映射为对应的 `pending` / `rejected` 状态。
- **📁 支持文件拖拽与自动检测**：支持上传/拖拽 `.json` 或 `.xml` (WXR) 文件，亦可直接粘贴内容，内置智能格式识别与实时预览诊断。

---

## 📖 平台操作指南

### 1. WordPress 数据迁移

#### 第一步：导出数据
1. 登录你的 WordPress 管理后台（`/wp-admin`）。
2. 在左侧菜单点击 **工具 (Tools)** $\to$ **导出 (Export)**。
3. 选择 **全部内容** 或 **文章**，点击 **下载导出的文件**，将获取一个 `.xml` 格式的 WXR (WordPress eXtended RSS) 文件。

#### 第二步：导入到 Qingniao
1. 登录 Qingniao 管理后台（`admin/index.html`）。
2. 点击操作栏上的 **📥 导入** 按钮。
3. 来源格式可选择 **「🤖 智能自动检测」** 或 **「🔷 WordPress」**。
4. **拖拽刚刚下载的 `.xml` 文件到虚线框**，或点击选择该文件（亦可直接用记事本打开并复制内容粘贴到输入框）。
5. 下方预览框将显示识别出的文章数与评论总数，确认后点击 **🚀 开始导入**。

---

### 2. Typecho 数据迁移

#### 第一步：导出数据
Typecho 通常通过导出插件或数据库导出评论：
- **方式一（推荐）**：使用 Typecho 导出插件（如备份插件或 Comments 导出工具）导出包含评论的 JSON 数据文件。
- **方式二（WXR 导出插件）**：若使用 `Export2Wordpress` 等插件导出为 WXR XML，操作步骤同 WordPress。

#### 第二步：导入到 Qingniao
1. 打开 Qingniao 管理后台并点击 **📥 导入**。
2. 来源格式选择 **「🔶 Typecho」**（或保留自动检测）。
3. 拖入导出的 `.json` 文件或粘贴 JSON 内容。
4. 检查预览诊断结果，点击 **🚀 开始导入**。

---

### 3. Waline 数据迁移

#### 第一步：导出数据
1. 登录 Waline 管理后台（例如部署在 Vercel / Netlify / 服务器上的后台）。
2. 依次点击 **系统管理** $\to$ **导出**。
3. 点击 **导出评论**，下载生成包含所有评论数据的 `.json` 文件。

#### 第二步：导入到 Qingniao
1. 打开 Qingniao 管理后台并点击 **📥 导入**。
2. 来源格式选择 **「🟢 Waline」**（或保留自动检测）。
3. 上传或粘贴导出的 `.json` 数据。
4. 预览框将自动识别出 Waline 格式并统计评论数量与回复关系，点击 **🚀 开始导入**。

---

### 4. Artalk 数据迁移

#### 第一步：导出数据
1. 登录 Artalk 管理后台。
2. 进入 **控制台** $\to$ **转移 / 备份** $\to$ **导出**。
3. 选择导出为 **Artrans (JSON)** 格式文件。

#### 第二步：导入到 Qingniao
1. 打开 Qingniao 管理后台并点击 **📥 导入**。
2. 来源格式选择 **「🟣 Artalk」**（或保留自动检测）。
3. 上传导出的 `.json` 文件或粘贴内容。
4. 系统将自动结合 `pages` 映射页面标题与路径，并还原 `rid` 回复层级，点击 **🚀 开始导入**。

---

### 5. Twikoo 数据迁移

### 第一步：从 Twikoo 导出数据
1. 登录你原有的 Twikoo 管理后台。
2. 点击顶部的 **设置** 或 **数据**。
3. 点击 **导出数据**，下载生成的 `.json` 文件。

### 第二步：导入到 Qingniao 管理后台
1. 打开 Qingniao 管理后台页面（`admin/index.html` 或你部署的后台地址）。
2. 输入管理员账号密码登录。
3. 点击操作栏上的 **📥 导入** 按钮。
4. 来源格式选择 **「🕊️ Twikoo」** 或保留 **「🤖 智能自动检测」**。
5. **直接拖拽导出的 `.json` 文件到虚线框**，或复制文件内容粘贴至文本框中。
6. 点击 **🚀 开始导入**。

导入完成后，系统会提示成功导入的数据条数，刷新后台即可查看并管理所有历史评论！

## 🛠️ 常见问题排查

1. **导入后历史评论在文章页面下没有显示？**
   - 评论是按照页面的 URL 路径（`page_path`）进行归属匹配的。例如 WordPress 导出的路径若为 `/2023/hello-world/`，而你新博客的路径为 `/posts/hello-world/`，请在管理后台确认页面路径是否一致。
2. **回复关系乱序或丢失？**
   - Qingniao 导入引擎在入库前会自动按照发表时间对评论进行正序排序，并动态映射父级 ID。只要原文件中包含父级 ID 标识（如 `comment_parent`, `parent`, `pid`, `rid`），即可 100% 还原嵌套回复结构。
3. **已审核用户的免审特权？**
   - 导入过程中，所有状态为已通过（`approved`）且带有有效邮箱的评论作者，其邮箱将自动注册至 `trusted_users` 信任库。后续该作者在博客中再次发表评论时，将自动免审直接发布。
